CSE 3220
Software Engineering Lab Project
Objective
Build a small but complete web application using Spring Boot, PostgreSQL, Spring Security, Docker, GitHub CI/CD, and Render deployment. The goal is NOT feature richness, but to demonstrate a complete professional software development workflow.
Team Requirements
This is a mandatory 3-person project. Each team must consist of exactly three members.
Mandatory Functional Requirements
1. Authentication & Authorization
Use Spring Security with: User Registration, Login/Logout, Password encryption (BCrypt), and Role-based authorization (ADMIN, SELLER, BUYER).
Access must be restricted using method-level security or URL-based configuration.
2. REST API Design
Follow REST principles with proper HTTP methods, status codes, and global exception handling. Minimum: 5 Controllers and CRUD for at least 3 main entities.
3. Database
Use PostgreSQL with at least 6 tables (e.g., User, Role, Product, Order), proper relationships (1:M, M:1, M:M), and JPA.
4. Testing
Include unit tests (Service layer) and integration tests (Controller layer) using JUnit, Mockito, SpringBootTest, and MockMvc. Minimum: 20 unit tests and 10 integration tests. Tests must run successfully in CI.
5. Dockerization
Include Dockerfile and docker-compose.yml with application and PostgreSQL containers. Use environment variables (no hardcoded credentials). The app must run using: 
'docker compose up --build'.
6. GitHub Requirements
Use branch strategy: main (protected), develop, and feature branches. No direct push to main. Pull request required with at least one review approval.
7. CI/CD Pipeline
Use GitHub Actions to build the project, run tests, and deploy to Render automatically from the main branch.
8. Deployment
Deploy on Render. Application must be publicly accessible. Submit live URL and GitHub repository link.

Required Deliverables
    • GitHub Repository
    • README with project description, architecture diagram, ER diagram, API endpoints, run instructions, CI/CD explanation
    • Deployed URL
    • 15 minutes demo presentation
